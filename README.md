# 👥 HR Analytics Dashboard (Tableau)

An interactive HR analytics dashboard built in Tableau, visualizing employee headcount, salary, working hours, leaves, job roles and locations to support data-driven workforce decisions.

## 📌 Project Overview
This project analyzes employee data stored in a MySQL database and presents key HR metrics through an interactive Tableau dashboard. It helps HR teams understand workforce distribution, salary expenses, leave patterns and working hours.

## 📊 Key Metrics
- Total Number of Employees
- Total Employee Salary
- Total Number of Leaves
- Total Working Hours

## 🔍 Analysis Dimensions
- Job Category
- Job Role
- Job Location
- Company Name

## 📈 Visualizations Used
- Pie Charts
- Bar Chart
- Line Charts
- Circle / Scatter View
- Text Tables (KPI cards)

## 🛠️ Tools & Techniques
- Tableau Desktop
- MySQL (data source)
- Calculated fields for KPIs
- Interactive dashboard design

## 📁 How to Use
1. Download `HR-Dashboard.twb` from this repository.
2. Open it in **Tableau Desktop** (or Tableau Public).
3. Reconnect the data source (MySQL employee database) if prompted.
4. Explore the dashboard.
